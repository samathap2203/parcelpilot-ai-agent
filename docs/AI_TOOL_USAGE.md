# AI Tool Usage Brief — ParcelPilot AI Support Agent

## AI Coding Tool Used

I used **ChatGPT** as an AI coding and development assistant during the implementation of the ParcelPilot AI Support Agent.

## How I Used It

ChatGPT was used to assist with:

* Understanding and breaking down the assessment requirements.
* Planning the agent architecture and project structure.
* Designing the separation between the agent, tools, data layer, document retrieval, reliability logic, and action workflows.
* Reviewing and improving Python implementation details.
* Debugging errors encountered during local development.
* Designing access-control and confirmation-based action workflows.
* Preparing the project README and setup instructions.
* Troubleshooting Git and GitHub repository setup.
* Troubleshooting deployment issues and interpreting application errors.

The generated suggestions were reviewed and tested during development. I made the final decisions about the implementation, project structure, functionality, and submission content.

ChatGPT was therefore used as a development assistant rather than as a replacement for testing or engineering judgment.
